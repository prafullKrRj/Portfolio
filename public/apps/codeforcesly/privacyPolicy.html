Introduction

Welcome to Codeforcesly - CF Helper, developed to provide users with a convenient way to visualize their Codeforces data. This privacy policy outlines the types of information the Application does and does not collect, store, and process. By using the Application, you agree to this privacy policy.

Data Collection

We respect your privacy and do not collect any personal or sensitive data from you. Specifically:

  • User Information:
    • The Application uses Codeforces public APIs to display user information and submissions.
    • The data retrieved from the Codeforces API is not stored or shared with any third party.
  • Friends Data:
    • The Application uses a local database to store friends' details for better visualization. This data is stored locally on your device and is not transmitted to any external server.
  • No Data Collection:
    • The Application does not collect, store, or share any personal information, usage data, or analytics.

Advertising

The Application does not include any advertisements. There is no data tracking or profiling for ad purposes.

Third-Party Services

The Application interacts only with the public APIs of Codeforces to fetch publicly available user information and submissions. For more information about Codeforces APIs, please refer to their official documentation.

Security

Since no user data is collected or transmitted, there is no risk of data breaches or unauthorized access via the Application. However, users are encouraged to manage their Codeforces credentials securely when using any third-party services.

User Control and Data Management

As no personal data is collected or stored by the Application, users have full control over their usage of the Application without any concerns about privacy violations.

Changes to This Privacy Policy

This privacy policy may be updated from time to time. Any changes will be communicated through the Application or by updating this document. Please review it periodically to stay informed about how your data is protected.
