CueSight

A Visual Blueprint for the Personal Social Interpreter

The Problem

Navigating a world of unspoken social cues is a major challenge for individuals with ASD or social anxiety, leading to misunderstanding and stress.

The Solution

A discreet system using smart glasses and a phone to provide real-time emotion detection and long-term behavioral insights, all processed privately on-device.

How It Chooses Who to Focus On

Primary Person Selection

In a scene with multiple people, CueSight must intelligently focus on the person the user is likely interacting with. It does this without facial recognition, using a simple but effective scoring system.

60% Weight: Largest face size (proximity).

40% Weight: Closest to the center of view.

🛡️

Privacy is Not an Option. It's the Foundation.

All processing is 100% on-device. No images, video, or personal data ever leave the user's phone. The system logs only anonymized summaries, ensuring complete user control and privacy.
